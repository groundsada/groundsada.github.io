# Welcome to My Blog

Welcome. This is my technical blog — a place to write about the work I do in research networking and scientific computing, and to leave breadcrumbs on the things I build and learn along the way.

## What to expect here

- **Research networking** — SENSE software-defined networking, multi-site orchestration, and how science traffic actually moves across the WAN.
- **Scientific data movement** — high-energy physics (HEP) transfer infrastructure, Rucio and FTS interoperability, and why network awareness matters for data pipelines.
- **Programmable data planes** — P4 on FPGAs, SmartNICs, and acceleration for packet processing.
- **AI/ML infrastructure** — gateways, observability, and getting models into production on shared research platforms like the National Research Platform (NRP).
- **Systems & DevOps** — Kubernetes, telemetry pipelines, and the small tools I write to make all of the above observable.

## About the site

This site is generated by a web framework written entirely in Bash (more in [my post about it](/blog/bash-stack-website)), pre-rendered to static HTML and served from GitHub Pages. Every post is a markdown file in this repository.

Find my code on [GitHub](https://github.com/groundsada), my papers on [arXiv](https://arxiv.org/abs/2609.13185), and my professional updates on [LinkedIn](https://www.linkedin.com/in/msada). Thanks for reading.
